# 业务 UI 修复 T02：统一业务筛选控件尺寸并修复搜索分页溢出

GitHub：[58](https://github.com/EziosWJ/simple-inventory/issues/58)

## What to build

经营者在购销和退货列表使用尺寸一致的状态筛选，在商品及往来单位搜索中正常阅读统计信息和操作分页。

## Acceptance criteria

- [ ] 采购、销售、采购退货、销售退货的状态筛选复用公共选择控件，单行高度 36px，并填满所属筛选列。
- [ ] 共享搜索触发按钮空值与单行高度为 36px，长描述仍自然换行增高，不截断商品或往来资料。
- [ ] 搜索分页启用紧凑布局，统计与翻页操作分行；240px 和 270px 容器内不溢出、不将统计文字挤成竖排。
- [ ] 覆盖采购/销售列表和录单、往来余额/明细、直送采购关联选择；两条结果和多页结果均可用。
- [ ] 零结果、加载、失败重试及页码变化正常；大表格默认分页、系统管理和示例页保持原行为。
- [ ] 1024px/1440px 浏览器回归和前端 lint/build 通过；库存调整自定义分页先补窄容器验证，确认缺陷后局部修复。

## Blocked by

None (can start immediately).
