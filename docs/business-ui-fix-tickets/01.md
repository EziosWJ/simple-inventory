# 业务 UI 修复 T01：采购销售录单返回时显示可见的离开确认

GitHub：[57](https://github.com/EziosWJ/simple-inventory/issues/57)

## What to build

经营者在采购、销售的新建和编辑页返回、内部跳转或后退时，能立即看到离开确认，选择继续编辑保留输入，选择离开返回正确来源。

## Acceptance criteria

- [ ] 离开决策使用居中弹窗，初始焦点位于继续编辑；表单很长或页面滚动后，提示仍在当前视口内。
- [ ] 两个顶部返回入口、菜单跳转、浏览器后退均有相同保护；无修改时直接离开，刷新和关闭标签页沿用原生提醒。
- [ ] 保存进行中不允许提前确认离开；保存失败保留输入；保存和过账结果待核实时保留原提醒、恢复标识及结果核实流程。
- [ ] 确认离开保留来源路径与原查询条件；继续编辑、关闭提示及 Escape 均留在原表单并保留输入。
- [ ] 交付供业务页面显式使用的共用确认能力；未接入的系统管理、示例与只读页面行为不变。
- [ ] 浏览器回归明确断言提示在视口内、焦点可操作，并覆盖购销新建和编辑；前端 lint/build 通过。

## Blocked by

None (can start immediately).
