# 业务 UI 修复 T04：业务新建和编辑弹窗关闭前保护未保存输入

GitHub：[60](https://github.com/EziosWJ/simple-inventory/issues/60)

## What to build

经营者在商品、往来单位、库存调整及两类退货的新建或编辑弹窗关闭前，能确认是否放弃已填写内容。

## Acceptance criteria

- [ ] 五类弹窗的新建和编辑均覆盖 X、Escape、遮罩、取消及内部导航离开；无修改直接关闭，已修改先确认。
- [ ] 继续编辑保留全部业务输入并恢复焦点；确认关闭才丢弃输入，重新打开不残留旧草稿。
- [ ] 提交期间禁止关闭，提交失败保留输入，成功关闭不出现额外离开确认。
- [ ] 嵌套确认时仅最上层弹窗接管键盘焦点，Escape 只处理顶层确认；不修改脚手架表单的默认行为。
- [ ] 退货来源查询参数引起的自动打开与离开确认协调，确认返回不能再次打开原弹窗。
- [ ] 隔离浏览器覆盖五类新建和编辑以及各关闭方式；前端 lint/build 通过。
