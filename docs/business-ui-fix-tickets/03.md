# 业务 UI 修复 T03：资料与资金录入页保护未保存输入

GitHub：[59](https://github.com/EziosWJ/simple-inventory/issues/59)

## What to build

经营者编辑仓库、经营者打印资料或填写收付款、退款、期初应收应付时，离开前可选择保留编辑或放弃输入。

## Acceptance criteria

- [ ] 五个业务页面接入统一离开确认，覆盖返回来源、菜单跳转、浏览器后退以及刷新和关闭提醒。
- [ ] 初始加载不视为用户修改；修改后恢复原值不提醒；保存成功更新基线，保存失败保留输入。
- [ ] 继续编辑保留金额、往来单位、日期及其余输入；确认离开到目标页面，保存期间不允许提前确认离开。
- [ ] 取消提交确认仅返回原表单，不丢输入；不把查询条件、只读页面或明确放弃的小流程当成编辑数据。
- [ ] 隔离浏览器覆盖全部五页、恢复原值及保存成功/失败；前端 lint/build 通过。
