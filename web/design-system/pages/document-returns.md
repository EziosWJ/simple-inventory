# 采购与销售退货详情、过账确认

退货列表继续使用 Standard List Page。详情使用 `DetailDialog` 的单据布局，过账沿用列表中既有草稿过账入口并使用 `FormDialog` 的单据布局；没有新增保存并过账流程。

详情概览优先展示本次退货金额、往来对象、状态和业务日期，并提供原采购／销售单跳转。商品明细先于备注、直送完整追溯和操作记录。数量分别标为原单数量、当前有效已退数量、当前剩余可退数量和本次退货数量。当前有效累计来自接口；已过账本单可能已包含其中，不在前端再次相加。原成交单价与退货行金额保持原值，不展示内部明细 ID。

草稿说明尚未改变库存、往来或有效额度；已取消单据保留原金额与数量，取消原因默认可见。直送详细关联表折叠显示，但采购退货须先过账关联销售退货的提示始终可见。

采购退货过账按商品身份和单位合并显示库存减少，抵减供应商方向往来；销售退货按相同规则显示库存增加，抵减客户方向往来。零金额说明往来余额无变化；实际退款须另行办理，不推断原单结清。提交沿用原退货 ID 与版本；确定失败留在确认弹窗，网络中断提示重新查询核实，不断言请求未生效。
