# 往来余额体验交付记录

规格：[GitHub #64](https://github.com/EziosWJ/simple-inventory/issues/64)，本地见[正式规格](partner-management-ux-spec.md)。用户已确认产品决策、测试边界并授权实施。

## 已实现

- 全店当前未结余额四项概览：客户应收、供应商应付、应退客户款、应收供应商退款，分别显示金额及单位数量；零余额和无记录方向不计入待处理统计。
- 客户应收／供应商应付前十名横向条形图，可切换方向、点击查明细。汇总和排名覆盖全店，不受列表搜索或分页影响。
- 分类列表默认客户应收，待处理分类按金额从大到小排列，同额按单位 ID 稳定排序；全部保留净结清和无记录方向。退款用明确资金方向及正数金额展示，明细和原 API 保留有符号余额。
- 搜索只影响列表，概览和图表明确标注全店范围；明细与资金页返回保留分类、单位筛选和页码。
- 收付款／退款使用分页往来选择器，带入单位与方向，支持填入全额或部分金额；格式、超额、余额加载失败有明确反馈，提交失败保留输入。
- 保存成功显示本次办理金额、余额变化及最新余额，提供返回／继续登记；返回重新加载概览、排名和列表，结清方向退出待处理分类，历史仍可追溯。
- 后端增加公开概览查询，余额分页查询新增可选分类。未提供分类的旧查询保持原单位方向排序与响应语义。
- 概览使用同一只读事务快照，流式读取整数分并精确累计；多个合法余额合计超过 int64 时仍准确，不使用浮点金额。排名和分类排序由服务端完成。
- 沿用原总余额结算、幂等、审计与事务校验，无 Schema、迁移版本、菜单或权限编码变更。REST 源注解及生成 Swagger 已同步。
