# 06：采购销售单据检索与历史停用资料查询

**GitHub issue:** [#45](https://github.com/EziosWJ/simple-inventory/issues/45) · `ready-for-agent`

## Parent

[Phase 5 规格 #39](https://github.com/EziosWJ/simple-inventory/issues/39)

## What to build

经营者按单号、交易对象、商品、状态和业务日期查采购/销售单，能找到停用及身份变化前的历史业务，从详情返回时保留查询条件。

## Acceptance criteria

- [ ] 采购/销售列表的查询、重置、条件改变和翻页行为统一，条件变化重置页码，迟到响应不覆盖当前筛选。
- [ ] 单号片段、对象 ID、商品 ID、状态和业务日期起止按既有公开契约组合过滤，同商品多行不重复计数。
- [ ] 对象/商品筛选使用可分页搜索并允许停用资料；往来当前身份改变不阻断其原采购/销售历史查询。
- [ ] 已选择对象不在搜索页中仍能正确显示，空结果、错误和重试清楚，超过 500 条仍能定位。
- [ ] 列表到详情/来源以及返回恢复对象、日期、状态、商品和页码上下文；原详情和新录单路由兼容。
- [ ] 历史单据展示过账快照含空值，不以当前档案重写历史；已取消记录可按状态检索，业务日期与实际操作时间仍区分。
- [ ] 双库公开查询契约及真实浏览器覆盖同名、停用、身份移除、多行计数、分页/重置/返回、原始与已取消记录。
- [ ] 保持旧查询参数及响应兼容，相关前后端检查与 API 文档同步完成。
