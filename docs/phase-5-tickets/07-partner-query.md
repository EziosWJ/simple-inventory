# 07：欠款查账、往来明细与来源追溯体验

**GitHub issue:** [#46](https://github.com/EziosWJ/simple-inventory/issues/46) · `ready-for-agent`

## Parent

[Phase 5 规格 #39](https://github.com/EziosWJ/simple-inventory/issues/39)

## What to build

经营者快速找到往来单位，分别看客户与供应商欠款，从余额进入正确方向和期间的明细，再追溯来源单据及返回查账上下文。

## Acceptance criteria

- [ ] 余额及明细入口使用可分页往来搜索，名称/编码/联系人/电话可查，包含停用及历史身份变化对象，已选 ID 独立保留。
- [ ] 客户/供应商方向分别展示，正欠款与负余额待退款的业务文案准确，两个方向不自动抵扣。
- [ ] 余额到明细携带单位和方向，日期筛选、期初/期间/期末及翻页沿用实际生效时间口径，同时显示业务日期。
- [ ] 采购/销售、退货、期初、收付款、退款和冲销来源均到正确已保存记录；往返保留对象、方向及期间。
- [ ] 原收付款、退款和对账打印入口可用，不增加逐单结清、账龄、普通预收预付或历史价格辅助。
- [ ] 查询加载、无结果、错误和重试清楚，保留现有公开接口及余额/流水语义。
- [ ] 双库公开契约和真实 UI 覆盖同一单位双向、待退款、停用、跨期补录/冲销、来源及完整期间打印。
- [ ] 相关前后端门禁完成；API 如有变更同步源注解与固定文档生成。
