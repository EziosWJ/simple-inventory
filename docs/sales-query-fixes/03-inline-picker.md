# 销售筛选输入框内置浏览选择入口

## Parent

https://github.com/EziosWJ/simple-inventory/issues/66

## What to build

销售出库的客户与商品筛选保留直接输入搜索，将独立的浏览选择按钮合并到输入框尾部，减少面板高度并保持两种查找方式。

## Acceptance criteria

- [x] 采用可输入搜索加尾部列表图标按钮；客户和商品筛选均不改为只读输入。
- [x] 尾部浏览按钮始终可见，有独立点击区域、悬停说明、可访问名称和键盘焦点；点击打开现有完整选择面板，不误触清除或关键词提交。
- [x] 选中显示可辨认名称，可清除并重新输入；尾部按钮、清除、输入文字互不遮挡。
- [x] 输入关键词、快速选取、浏览分页选择与历史停用资料查询继续可用，不改变商品 ID 和关键词的互斥查询规则。
- [x] 客户提示为搜索名称、编码、联系人或电话；商品提示为搜索名称、编码、品牌或型号，与各自真实支持范围一致。
- [x] 仅在销售出库显式启用该布局；其他页面和录单选择器的默认展示及业务规则保持兼容。
- [x] 真实浏览器验证输入、选择、清除、键盘及常用电脑宽度下的一行布局，通过前端 lint/build。

## Blocked by

无，可立即开始。
