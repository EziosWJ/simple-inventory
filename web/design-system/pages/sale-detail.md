# 销售单详情

沿用 Detail Page 模式，以 `SaleDetail` 和 `DetailDialog` 从销售列表或来源链接打开。

- 桌面端宽度上限 1100px、高度上限 90dvh，用于核对商品名称、规格、数量和金额；窄屏全屏，商品表格横向滚动。
- 固定头部及底部操作区，正文独立滚动。`DetailDialog.fixedFooter` 为可选能力，仅销售详情启用。
- 正文依次展示金额和生效说明、商品明细、单据备注，再按需展开送货资料、采购来源、关联直送单据及操作记录。
- 来源采购取消或退货的核对提示、当前单据取消原因默认可见，不随辅助信息折叠。
- 商品名称为主，编码及型号规格为辅；数量附单位，不合计不同单位的数量。服务单不显示办理实物退货入口。
- 已过账普通销售突出打印送货单，草稿突出编辑；直送生成单提供来源直送单入口，沿用统一确认和取消规则。
- 不以单据金额推断收款或结清状态；零金额与仅服务单据分别说明往来及库存影响。

本轮调整详情展示和已有操作的布局。有效退货汇总、净销售额及新增过账/取消入口留待后续实现。
