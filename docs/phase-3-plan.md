# Phase 3 库存基础需求讨论记录

本文记录下一阶段访谈中已确认的决策。Q1–Q20 已逐轮确认，Q21 已确认完整规格，需求访谈完成。正式规格已发布为 [GitHub #7](https://github.com/EziosWJ/simple-inventory/issues/7)，本地副本见 [Phase 3 库存基础规格](phase-3-spec.md)；六个实现任务已发布，尚未开始功能实现。

## 已确认

- Q1：先交付库存基础（Phase 3），包括现有库存录入、当前库存查询、库存流水和库存调整。
- 采购入库、销售出库单据随后接入，本轮不合并交付进销存闭环。
- Q2：本轮只管理库存数量，不管理库存成本及金额；成本核算留到采购、销售阶段讨论。
- Q3：本轮按商品汇总数量，不逐台记录序列号（SN）；逐台追踪留到出入库阶段讨论。
- Q4：现有库存通过库存调整单录入，原因标记为“期初录入”，本轮不设独立期初确认和锁定流程。
- Q5：禁止负库存。任何导致库存数量小于零的变动均应拒绝，取消操作产生的反向变动也须遵守此约束。
- Q6：库存调整填写增减数量，并必填调整原因；本轮不提供输入盘点实存数量并自动计算差额的专门盘点流程。
- Q7：调整单先保存为草稿，再明确执行过账；草稿可编辑，过账后内容锁定，取消已过账单据时生成反向流水。
- Q8：一张调整单支持多个商品及不同商品分别增减；同一商品只能出现一次，整单一起过账或取消，不做部分过账或部分取消。
- Q9：调整原因采用“期初录入、盘盈、盘亏、报损、其他”分类，允许补充说明；选择“其他”时必须填写说明。
- Q10：商品产生过库存流水后，永久禁止修改商品类型和基本单位，即使相关调整已取消也不解除限制；名称、型号等描述可继续编辑。决策依据见 [ADR-0012](adr/0012-product-inventory-identity-lock.md)。
- Q11：库存变动按系统实际过账时间记录，不支持倒签或重算历史库存；此前发生的情况写入说明。
- Q12：每条明细分别选择调整原因。期初录入、盘盈只能增加，盘亏、报损只能减少，其他允许增减且必须填写说明。
- Q13：停用商品不能加入新调整单，包含停用商品的草稿不能过账；需要调整时先重新启用。停用商品的库存和历史仍可查询，已过账单据可按非负库存约束取消。
- Q14：已过账调整单和流水保留过账时的商品编码、名称、型号、规格、单位快照，历史按快照展示，并关联当前档案。
- Q15：当前库存默认展示所有非零库存，包括停用商品；可切换全部或零库存，支持关键词、分类、启用状态筛选。服务项目不进入库存列表。
- Q16：沿用 Phase 2 的已登录账号访问范围；已登录账号可查看、维护草稿、过账和取消任意调整单，记录实际操作人，不新增操作权限或单据所有权限制。
- Q17：系统自动生成唯一且不可修改的单号；草稿可取消且不产生库存流水。所有已保存单据均保留，不提供删除，取消时必须填写原因。
- Q18：填错的已过账单据能够取消时，先取消再新建正确单据；无法取消时，根据实际库存另建调整单纠正，在说明中注明原单号。已取消单据不重新过账，原记录始终保留。
- Q19：拒绝以旧版本草稿覆盖别人已保存的修改，提示刷新核对。草稿中的类型或单位与当前档案不一致时，禁止过账，要求重新选择商品并确认数量；过账时重新校验商品状态和库存余额。
- Q20：调整单按单号、状态、商品、创建时间查询，详情包含明细、原因、说明及创建/过账/取消的操作人和时间。流水按商品、发生时间、原始变动/取消冲销查询，展示增减数量、变动前后余额、原因、操作人并关联来源单据。当前库存可直接进入商品流水；本轮分页查询，导出和打印留到后续阶段。

## 沿用的项目约束

以下约束来自现有 CONTEXT.md 和 Phase 2 规格，不代表本轮新增确认的规则：

- 使用唯一逻辑仓库，实物商品参与库存，服务项目不产生库存。
- 数量允许三位小数；参考采购价不代表实际库存成本。
- 库存由当前余额和不可变库存流水共同表达，只有过账改变库存，已过账取消通过反向流水处理。
- 核心业务写入与操作审计保证事务一致性，支持 PostgreSQL 和 SQLite。
- Phase 2 允许编辑商品类型和基本单位；本轮按 Q10 补充产生库存历史后的修改限制。

## 设计树

```text
Phase 3 库存基础（Q1）
├── 管理边界：数量、按商品汇总、期初共用调整、非负、增减录入（Q2–Q6）
├── 调整单：草稿/过账/取消、多商品、原因、实际过账时间（Q7–Q9、Q11）
│   ├── 每行原因与方向约束（Q12）
│   ├── 停用商品与资料变化（Q13、Q19）
│   └── 编号、保留、取消及纠错路径（Q17–Q18）
├── 历史身份：类型/单位锁定、过账资料快照（Q10、Q14）
└── 使用与追溯：库存展示、登录访问、单据/流水查询（Q15–Q16、Q20）
```
