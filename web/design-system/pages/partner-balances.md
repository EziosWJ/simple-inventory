# 往来余额页面覆盖规则

采用 Standard List Page 的业务扩展：PageHeader 后增加全店未结余额概览与金额排名，随后沿用 SearchFilterBar、DataTableCard、DataTable、Pagination。概览与图表回答全店资金分布，列表承载具体单位查询和办理，三个范围明确区分。

沿用主规范蓝灰色、现有字体栈和 tabular-nums。全店概览用一组共享边框的四项指标，点击切换款项分类；排名用主色横向条形长度比较金额，不添加装饰动画或图表依赖。金额字号为 24px，单位名称左对齐、金额右对齐。列表保留高密度行操作与窄屏横向滚动。

退款用明确资金方向及正数金额表达，明细仍保留有符号余额。加载期间不显示虚构零金额；概览和排名总是标注全店范围，搜索只影响列表。
