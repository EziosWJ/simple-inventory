# 销售过账确认准确表达商品与库存影响

## Parent

https://github.com/EziosWJ/simple-inventory/issues/66

## What to build

过账前准确展示每种实物的库存扣减，让同名不同规格商品、小数数量和混合服务销售都能被经营者正确核对。

## Acceptance criteria

- [x] 库存影响按商品 ID 和单位归集，显示可辨认的编码、名称、型号规格和单位；同名不同商品不合并，同商品分行可以准确汇总。
- [x] 数量使用既有精度的定点或 decimal 计算与格式化，不用浮点近似累加生成提示；例如 0.1 加 0.2 显示 0.3。
- [x] 混合服务和纯服务销售正确表达实物库存影响；服务不产生库存扣减，零金额实物销售仍展示数量扣减。
- [x] 保留整单过账确认及应收影响，不改变服务端过账事务、版本保护、库存、往来或审计规则。
- [x] 真实浏览器验证同名不同规格、小数数量、不同单位、混合/纯服务和零金额销售的确认内容；验证过账结果与提示一致。
- [x] 通过前端 lint/build，涉及后端改动时执行相应检查。

## Blocked by

无，可立即开始。
