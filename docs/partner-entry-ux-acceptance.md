# 收付款、退款、期初往来体验修正

日期：2026-10-14。

针对原先常驻表单、重复方向选择及新增说明拉长页面的问题，改为记录列表和页头登记按钮。点击按钮打开指定方向的短表单，核对在同一弹窗中完成，保存后返回列表。现有来源链接自动带入对象和方向，记录链接直接打开详情。

金额改为实际收付正金额与“客户还欠／还欠供应商／还需退给客户／供应商还需退回”的表达；历史前后余额与登记结果均明确是该笔生效时的快照。期初重复提醒基于实际未冲销期初笔数；冲销核对读取当前余额，原记录与冲销记录提供互相追溯入口。

根据余额区域反馈，当前金额使用浅蓝摘要、30px 加粗和千位分隔。点击查看明细会在登记弹窗内查询该单位对应方向的全部往来，支持分页、失败重试和收起；不跳转页面、不丢失登记金额。展开前不查询此明细，切换对象后不会保留旧明细。
