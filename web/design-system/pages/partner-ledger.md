# 往来明细的记录与来源细节

采用 Standard List Page，单据记录使用 DetailDialog；复用 DataTable 的展开行能力，不新增页面模式。

- 点击单号打开记录弹窗，突出往来余额增减金额与本笔生效前后余额。日期、实际生效、操作人和说明分别表达。正文滚动、关闭操作固定，长单号可换行。
- 列表的“展示细节”在该行下方按需读取来源；弹窗内提供相同的按需展开。收起、失败重试和查看均不跳转页面或产生业务写入。
- 采购、销售、退货展示来源当前状态、单号、往来单位、日期、单据金额及商品快照、数量、成交单价、行金额；服务保留服务标记。退货同时展示原单号。
- 收付款、退款、期初展示实际金额、方式、流水号、说明及操作信息。冲销通过 reversesId 读取原业务，而不是使用冲销记录的金额伪造原单据。
- 明确区分来源当前状态与往来记录本笔生效时的金额及前后余额；取消原因和历史原内容保留。
- 翻页、更换查询或刷新后清除展开，关闭或收起后忽略迟到响应。来源缺失与加载失败在当前展开区显示，并提供重试。

专项入口：`node tests/ledger-source-details.mjs`。模拟 API 验证界面行为，不替代真实双库事务验证。
