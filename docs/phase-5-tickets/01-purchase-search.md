# 01：采购录单商品与供应商分页搜索

**GitHub issue:** [#40](https://github.com/EziosWJ/simple-inventory/issues/40) · `ready-for-agent`

## Parent

[Phase 5 规格 #39](https://github.com/EziosWJ/simple-inventory/issues/39)

## What to build

经营者在现有采购录单入口按商品资料或供应商联系方式搜索并选择正确对象，资料超过 500 条仍能完整检索；首个可用场景同时建立后续复用的选择能力。

## Acceptance criteria

- [ ] 采购商品支持编码、名称、品牌、型号、规格片段；供应商支持编码、名称、联系人、电话片段，结果含可辨认信息并绑定内部 ID。
- [ ] 复用现有分页 API，关键词字面匹配和字母大小写行为双库一致；稳定排序、总数及翻页正确，不只过滤首批 500 条。
- [ ] 采购仅选择启用供应商和实物商品；选中对象可按 ID 加载，不在当前结果页时仍保留，编辑草稿里的停用资料明确标识。
- [ ] 加载、空结果、失败、重试、翻页和快速切换关键词正确；迟到响应不覆盖当前查询。
- [ ] 共用选择能力支持类型、身份和启用/历史查询配置，随采购场景落地，不引入全局搜索框架。
- [ ] 公开 HTTP 双库与真实浏览器覆盖超过 500 条、同名、型号/联系方式、字面百分号/下划线、大小写、停用及错误类型/身份。
- [ ] 保持当前采购保存、编辑、过账和直送行为可用；相关后端及前端检查通过，API 变更同步源注解并运行固定文档生成入口。

## Blocked by
